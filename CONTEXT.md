# PokeTrader

PokeTrader supports exchanges of Pokemon between players using FireRed or LeafGreen.

## Language

**Local trade**:
A trade using the existing nearby 3DS and Switch arrangement.

**Remote trade**:
A trade between friends whose consoles use separate bridges, whether on the same network or different networks.
_Avoid_: Global trading, which can suggest public matchmaking

**Private room**:
A meeting place for two friends arranging a remote trade, shared through a room code outside PokeTrader.

**Offer**:
The exact Pokemon a player proposes to exchange. Both players must accept both offers before either side commits the exchange.

**Approval**:
A player's acceptance of the exact pair of offers. Any change to either offer invalidates both players' approvals, even when the displayed summaries look identical.

**Pending exchange**:
An exchange that has begun but still needs completion or recovery. Once either side may have committed, it remains pending without automatic expiry and blocks conflicting trades until resolved.
